

# 🎮 Simon Game

## 📌 Overview
The **Simon Game** is a classic memory-based game built using **HTML, CSS, and JavaScript**. The objective is simple yet challenging: repeat the sequence of colors and sounds generated by the game. With each round, the sequence grows longer, testing your memory and concentration.

## ✨ Features
- 🎨 Interactive UI with colorful buttons  
- 🔊 Sound effects for each button press  
- 🧠 Increasing difficulty as the sequence grows  
- ⏱️ Real-time feedback on correct/incorrect moves  
- 📱 Responsive design for desktop and mobile  

## 🚀 How to Play
1. Press any key to start the game.  
2. Watch the sequence of colors and sounds carefully.  
3. Repeat the sequence by clicking the buttons in the same order.  
4. Each round adds a new step to the sequence.  
5. If you make a mistake, the game ends — try again to beat your high score!  

## 🛠️ Tech Stack
- **HTML5** – Structure  
- **CSS3** – Styling and animations  
- **JavaScript (ES6)** – Game logic and interactivity
